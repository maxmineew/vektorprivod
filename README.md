# ВекторПривод — портфолио-демо сайта-визитки B2B

**Live:** https://maxmineew.github.io/vektorprivod/  
**Repo:** https://github.com/maxmineew/vektorprivod

Статический аналог ТЗ с Fl.ru (сайт-визитка для промышленности), **без привязки к металлопрокату и без Signea**.

## Вымышленный бренд

| | |
|---|---|
| **Компания** | ООО «ВекторПривод» |
| **Сфера** | промышленные редукторы, электродвигатели и приводная комплектация |
| **Партнёр (вымысел)** | Hangzhou DriveTech Co., Ltd |
| **Домен в текстах** | `vektorprivod.example` (не боевой) |

## Что реализовано по структуре ТЗ

- 5 страниц: Главная, О компании, Каталог, Поставки из Китая, Контакты  
- единый header: лого, меню, телефон/email, «Заказать звонок», «Заявка в 1 клик»  
- слайдер на главной (2 слайда, автопрокрутка + стрелки/точки)  
- 7 групп каталога на главной + полный каталог **38 карточек** (без внутренних страниц товара)  
- 5 услуг, этапы поставок, 5 логистических маршрутов  
- формы (модалки + контакты) — демо-submit без бэкенда  
- SEO-база: title, description, h1–h2, ЧПУ-имена файлов, alt через aria у SVG  
- адаптив desktop / mobile  
- стиль: металл / сталь / синие акценты (Teko + IBM Plex Sans)

## Стек для портфолио

Чистый **HTML / CSS / JS** (без CMS) — удобно выложить на GitHub Pages / Netlify и дать одну ссылку в отклике.  
Для реального заказа по ТЗ в отклике по-прежнему логичен **WordPress**.

## Как открыть локально

```bash
cd "Моя ИИ студия/Портфолио/sites/vektorprivod"
# вариант 1
start index.html

# вариант 2 (если нужен локальный сервер)
npx --yes serve .
```

## Как писать в портфолио / отклике

> Многостраничный B2B сайт-визитка для промышленного поставщика привода: 5 страниц, каталог-витрина 7×38, формы заявок, блок импорта из Китая, адаптив. Живое демо: *[ссылка после деплоя]*.

В футере помечено: «Демо для портфолио» — чтобы не путали с реальным юрлицом.
